한 번 설치하고,
강의 창만 열어두세요.

크롬에 확장 추가

  1. Python 3.12 (64비트)를 설치한 뒤, 프로젝트 폴더의 setup.cmd를 실행합니다. 필요한 패키지 설치와 크롬 연결을 함께 진행합니다.
  2. 이미 설치했거나 프로젝트 폴더를 옮겼다면 install-chrome.cmd로 크롬 연결을 다시 등록합니다.
  3. 크롬 주소창에 chrome://extensions를 입력합니다.
  4. 오른쪽 위 개발자 모드를 켭니다.
  5. 압축해제된 확장 프로그램을 로드합니다를 누릅니다.
  6. 이 프로젝트 안의 extension 폴더를 선택합니다.
  7. 크롬에서 한성 eClass에 로그인한 뒤, 과목 페이지에서 강의 동영상 창을 엽니다.

영상 주소가 감지되면 다운로드 → 음성 추출 → 스크립트 생성 → 처리용 영상·음성 삭제가 자동으로 이어집니다. 재생을 눌러야 주소를 제공하는 영상은 한 번 재생하세요.

이미 열려 있던 과목·동영상 페이지는 확장 설치 후 새로고침하세요. 진행 상황은 확장 아이콘을 누르면 볼 수 있습니다.

대본·자막 저장이 모두 성공하면 처리용 영상·음성과 임시 파일을 삭제합니다. 실패·중단된 작업의 파일과 사용자가 선택한 로컬 원본은 보존합니다. 과목명을 찾지 못하면 과목 미지정에 저장됩니다. 확장 팝업에서 과목명을 입력하고 재시도할 수 있습니다.

완료한 강의를 다시 열면 기존 대본·자막을 사용합니다. 완료 후 현재 영상 시작 / 재시도를 누르면 영상을 다시 다운로드합니다.

사용 중

처리 중에는 크롬을 켜두세요. 확장 팝업이나 강의 탭은 닫아도 처리가 이어집니다. 크롬을 종료하면 중단되며, 같은 강의를 다시 열면 저장된 영상·음성과 완료한 전사 구간을 사용합니다.

자동 실행은 한성 eClass 동영상 창에 적용됩니다. 다른 사이트는 동영상 페이지에서 확장 팝업의 현재 영상 시작 / 재시도를 누릅니다. MP4, HLS, DASH를 감지하며 DRM 영상은 지원하지 않습니다.

start.cmd는 저장 기록 확인과 내 동영상 파일 처리를 위한 창입니다. 자동 저장에는 이 창을 켜둘 필요가 없습니다.
